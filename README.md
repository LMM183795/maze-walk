# 走迷宫

网页版迷宫小游戏：随机生成迷宫，找到金色出口即可进入下一关。关卡越大，迷宫越大。

## 在线试玩

https://maze-walk.vercel.app

## 操作

- 鼠标：轻点走一步，按住朝鼠标方向连续移动
- 键盘：方向键或 `WASD`
- 手机：滑动，或使用屏幕方向按钮

## 难度

- 轻松：第 1 关 9×7
- 标准：第 1 关 11×9
- 挑战：第 1 关 15×11

每过一关迷宫会继续变大，难度选择会保存在本机。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```
