# 走迷宫

网页版迷宫小游戏：随机生成迷宫，找到金色出口即可进入下一关。关卡越大，迷宫越大。

## 在线试玩

https://maze-walk.vercel.app

## 操作

- 鼠标：轻点走一步，按住朝鼠标方向连续移动
- 键盘：方向键或 `WASD`，按住可连续移动
- 手机：滑动，或使用屏幕方向按钮

## 难度

- 轻松：第 1 关 9×7
- 标准：第 1 关 11×9
- 挑战：第 1 关 15×11
- 魔王：第 1 关 23×17

每过一关迷宫会继续变大，难度选择会保存在本机。所有方块使用相同亮度的随机颜色，只有不可走的墙体带叉号。金色出口不再固定在右下角，每关会随机出现在离起点较远的通道里。

魔王难度没有环路，并额外启用局部迷雾和假出口：走过的区域会变暗，死路中会出现与真出口相同的金色假出口，踩中加 5 秒罚时。挑战难度保留少量环路。
